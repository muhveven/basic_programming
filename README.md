# Pemrograman Dasar - RPE311

## Versi Indonesia

### Deskripsi

Folder ini digunakan sebagai tempat akses materi, bahan ajar, dan kegiatan perkuliahan untuk mata kuliah Pemrograman Dasar pada Program Studi Teknologi Rekayasa Pembangkit Energi. Folder ini berfungsi sebagai pusat dokumentasi pembelajaran yang mencakup berbagai materi perkuliahan, tugas, serta referensi pendukung untuk mendukung proses belajar mengajar.

Mata kuliah ini memiliki kode matakuliah: RPE311. Folder ini dibuat agar mahasiswa dapat dengan mudah mengakses materi pembelajaran, mengelola bahan kuliah, dan mengikuti proses perkuliahan secara terstruktur.

### Isi Folder

- Materi perkuliahan
- Referensi dan modul pembelajaran
- Dokumen RPS dan perencanaan perkuliahan
- Arsip materi per minggu
- Bahan pendukung kegiatan belajar

## I. DEFINISI ISTILAH

**Student Outcomes (SO)**  
Kriteria pengetahuan, keterampilan, kemampuan, atau sikap yang diharapkan dapat dicapai mahasiswa pada akhir pengalaman belajar atau program studi.

**Performance Indicator (PI)**  
Kinerja konkret yang dapat diukur dan harus dipenuhi mahasiswa sebagai indikator pencapaian.

**Course Learning Outcomes (CLOs)**  
Pernyataan spesifik dan terukur yang menjelaskan pengetahuan, keterampilan, dan sikap yang akan ditunjukkan oleh mahasiswa setelah menyelesaikan suatu mata kuliah.

---

## II. COURSE DESCRIPTION

Mata kuliah ini membahas fundamental pemrograman (logika, struktur data, algoritma) serta konsep inti pengolahan, analisis, dan interpretasi data yang diterapkan pada data operasional pembangkit listrik dan sistem tenaga listrik. Mahasiswa akan mempelajari penggunaan bahasa pemrograman Python untuk mengidentifikasi pola dan tren dalam data sektor energi, menghasilkan insight, serta menyajikan hasil analisis dalam format yang jelas untuk mendukung pengambilan keputusan dan pemecahan masalah di bidang teknik pembangkit energi.

---

## III. COURSE GOAL

- Menetapkan landasan berpikir komputasional
- Menghubungkan teori pemrograman dengan aplikasi dunia nyata di bidang pembangkit energi dan teknik energi.
- Mengembangkan kompetensi inti dalam siklus analisis data menggunakan data sektor energi.
- Melengkapi keterampilan dalam storytelling data dan visualisasi untuk pemantauan kinerja pembangkit.
- Menumbuhkan kesadaran etis dan kritis dalam menangani data infrastruktur kritis (energi).
